## Why

Audio Backuper — отдельный мини-продукт: плагин на мастер-шине, который копирует новые и изменённые рендеры из папки в облако пользователя. Прототип до продукта не дотягивает (разбор — `openspec/audio-backuper.md`): загрузка в исходниках отправляет мусор вместо файла, локальный API отдаёт токен облака любой веб-странице, плагину нужен установленный Node.js, изменённые файлы не копируются, Google Drive нет. Относится к треку B roadmap.md — текущий приоритет.

## What Changes

- **BREAKING** Фоновая часть переписывается на Go как помощник внутри бандла плагина; Node.js-сервис `backuper-service/` удаляется после достижения паритета. Установленный Node.js больше не нужен.
- **BREAKING** Локальный API заменяется: случайный порт, обязательный секрет, отказ запросам из браузера, секреты не возвращаются. Файл `~/.audio-backuper.json` больше не используется; токен из него не переносится — вход выполняется заново.
- Один помощник на пользователя для всех экземпляров плагина и всех DAW; он догружает очередь после закрытия DAW.
- Копируются новые **и изменённые** файлы; файлы, появившиеся при выключенном помощнике, подхватываются при следующем запуске; очередь переживает перезапуск.
- Второе облако — Google Drive; вход в оба облака через браузер; токены в системном хранилище секретов.
- В облаке сохраняется структура папок; прежняя версия изменённого файла не теряется.
- Окно плагина: вход в облако, папка проекта и папка в облаке, ход загрузки, ошибки с понятным действием. Привязка папки сохраняется в проект DAW.
- Плагин перестаёт блокировать интерфейс DAW и запускать процессы при подготовке звука; принимает любую раскладку каналов.
- Помощник попадает в бандл плагина при сборке.

Вне рамок: установщики, подпись и нотаризация, автообновление (отдельное изменение `package-audio-backuper`); дедупликация и история версий SoundGit; загрузка в обратную сторону (из облака на диск); общий доступ к файлам; ограничение скорости; другие облака.

## Capabilities

### New Capabilities

- `cloud-accounts`: подключение облака — Яндекс Диск и Google Drive, вход через браузер, права, хранение и обновление доступа, выход.
- `backup-helper`: фоновый помощник — запуск из бандла, один на пользователя, работа после закрытия DAW, защищённый локальный API.
- `backup-plugin`: плагин в DAW — поддерживаемые хосты, отсутствие влияния на звук и интерфейс, настройка и состояние в окне, сохранение привязки в проект.

### Modified Capabilities

- `audio-backup`: правила копирования меняются целиком — папки на проект, новые и изменённые файлы, догон, расположение и версии в облаке, проверка целостности, постоянная очередь, классы ошибок. Требования об управлении через локальный API, хранении настроек и роли плагина переезжают в новые возможности.

## Impact

- Код: новый исполняемый файл `core/cmd/audio-backuper-helper` и пакеты `core/internal/backuper/…` в существующем Go-модуле; переписывается `juce-client/Source/*` и `juce-client/CMakeLists.txt`; удаляется `backuper-service/`.
- Новые зависимости Go: наблюдение за файловой системой, системное хранилище секретов.
- Сборка плагина начинает требовать Go.
- CI: сборка плагина на macOS и Windows.
- **Нужно от автора:** зарегистрированные приложения в Google Cloud и Яндекс OAuth (идентификаторы клиента) — без них вход через браузер нельзя проверить на настоящих облаках; проверка в Logic Pro и Ableton Live руками; машина с Windows.
- README: разделы сборки, настройки и HTTP API переписываются.
