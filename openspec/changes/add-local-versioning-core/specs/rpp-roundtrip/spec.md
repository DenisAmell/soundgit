## Purpose

Чтение файла проекта Reaper (`.rpp`) в древовидное представление и запись обратно без потери каких-либо данных, включая конструкции, смысл которых системе неизвестен.

## ADDED Requirements

### Requirement: Круг чтения и записи без потерь

Система SHALL при чтении файла `.rpp` и записи результата без изменений выдавать файл, побайтово совпадающий с исходным.

#### Scenario: Проект из корпуса

- **WHEN** файл проекта из тестового корпуса прочитан и записан без изменений
- **THEN** записанный файл побайтово совпадает с исходным

#### Scenario: Окончания строк Windows

- **WHEN** прочитан и записан файл с окончаниями строк CRLF
- **THEN** окончания строк в записанном файле сохранены

#### Scenario: Неизвестные блоки

- **WHEN** файл содержит блоки и атрибуты, не известные системе (например, данные сторонних расширений)
- **THEN** они присутствуют в записанном файле без изменений и на исходных местах

### Requirement: Разбор токенов и кавычек

Система SHALL различать токены, разделённые пробелами, и строковые токены в кавычках `"`, `'` и `` ` ``, сохраняя исходный вид кавычек.

#### Scenario: Имя дорожки с пробелами и кавычками

- **WHEN** имя дорожки содержит пробелы и символ двойной кавычки
- **THEN** имя прочитано целиком как одно значение
- **AND** при записи используется тот же вид кавычек, что в исходном файле

### Requirement: Многострочные данные блоков

Система SHALL сохранять многострочное содержимое блоков состояния плагинов и MIDI-источников без изменений.

#### Scenario: Состояние плагина

- **WHEN** проект содержит эффект с состоянием в base64 на нескольких строках
- **THEN** после круга чтения и записи строки состояния идентичны исходным

### Requirement: Диагностика повреждённого файла

Система MUST отказывать в разборе структурно некорректного файла с сообщением, содержащим номер строки, и не создавать частичный результат.

#### Scenario: Незакрытый блок

- **WHEN** в файле отсутствует закрывающая строка блока
- **THEN** разбор завершается ошибкой с номером строки открытия блока

#### Scenario: Файл не является проектом Reaper

- **WHEN** на вход подан файл, не начинающийся с блока проекта Reaper
- **THEN** разбор завершается ошибкой, объясняющей, что формат не распознан

### Requirement: Одинаковый результат на всех платформах

Система SHALL давать идентичный результат записи на macOS, Windows и Linux для одного и того же входного файла.

#### Scenario: Сравнение между платформами

- **WHEN** один и тот же файл корпуса прочитан и записан на трёх ОС
- **THEN** все три записанных файла побайтово совпадают
