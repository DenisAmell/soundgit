## Why

Audio Backuper собран и проверен в Reaper, но поставить его можно только сборкой из исходников на своей машине. Чтобы плагином мог пользоваться другой человек (а автор — проверить его в Logic Pro, Ableton Live и под Windows на чистой машине), нужен установщик. Относится к треку B roadmap.md, следующий шаг после `rebuild-audio-backuper`.

## What Changes

- Установщик для macOS (`.pkg`): AU и VST3, универсальные (Intel и Apple Silicon), установка для всех пользователей или только для текущего.
- Установщик для Windows (`.exe`): VST3, с удалением через «Установка и удаление программ».
- Обновление поверх работающего помощника: установщик корректно заменяет файлы, очередь загрузки не теряется.
- Подпись разработчика и нотаризация (macOS), подпись кода (Windows) — когда заданы учётные данные; без них получается сборка для проверки, честно помеченная как неподписанная.
- Одна версия на плагин, помощника и установщики, из одного источника.
- Сборка выпуска в CI: по тегу или вручную собираются оба установщика, каждый там же устанавливается и проверяется, артефакты прикладываются к черновику выпуска.

Вне рамок: автообновление и проверка новой версии из плагина; установщик для Linux; формат AAX; магазины приложений; получение сертификатов (делает автор).

## Capabilities

### New Capabilities

- `backup-distribution`: поставка Audio Backuper — установка, обновление и удаление на macOS и Windows, подпись, согласованность версий, сборка выпуска.

### Modified Capabilities

Нет.

## Impact

- Новые каталоги: `tools/packaging/macos`, `tools/packaging/windows`; новый workflow `backuper-release`.
- `juce-client/CMakeLists.txt`: версия плагина берётся из версии помощника.
- README: раздел установки.
- **Нужно от автора для подписанных сборок:** учётная запись Apple Developer (сертификаты Developer ID Application и Developer ID Installer, пароль приложения для нотаризации) и сертификат подписи кода для Windows. Без них выпускаются неподписанные сборки для проверки.
