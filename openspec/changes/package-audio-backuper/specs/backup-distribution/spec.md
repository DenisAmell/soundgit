## Purpose

Поставка Audio Backuper пользователю: как плагин устанавливается, обновляется и удаляется на macOS и Windows, как подтверждается подлинность сборки и как собирается выпуск.

## ADDED Requirements

### Requirement: Установщик для macOS

Система SHALL поставляться для macOS одним установщиком, который ставит плагин в форматах Audio Unit и VST3 для компьютеров на Intel и на Apple Silicon.

#### Scenario: Установка для всех пользователей

- **WHEN** пользователь запускает установщик и выбирает установку для всех пользователей
- **THEN** плагин появляется в системных папках плагинов и виден в DAW после её перезапуска

#### Scenario: Установка только для себя

- **WHEN** пользователь выбирает установку только для себя
- **THEN** плагин ставится в его домашний каталог без запроса пароля администратора

#### Scenario: Компьютер на Intel

- **WHEN** установщик запущен на компьютере с процессором Intel
- **THEN** плагин и помощник работают без дополнительных действий

### Requirement: Установщик для Windows

Система SHALL поставляться для Windows установщиком, который ставит плагин VST3 в стандартную папку VST3 и регистрирует его удаление в системе.

#### Scenario: Установка

- **WHEN** пользователь запускает установщик
- **THEN** плагин появляется в стандартной папке VST3 и виден в DAW после её перезапуска

#### Scenario: Удаление через систему

- **WHEN** пользователь удаляет программу через системный список установленных программ
- **THEN** файлы плагина удалены

### Requirement: Ничего, кроме установщика

Установка MUST NOT требовать от пользователя отдельно ставить другие программы или среды выполнения.

#### Scenario: Чистая машина

- **WHEN** установщик запущен на машине, где есть только DAW
- **THEN** после установки плагин загружается и запускает помощника

### Requirement: Обновление поверх работающей версии

Установщик SHALL заменять установленную версию, в том числе при работающем помощнике, не теряя очередь загрузки и настройки.

#### Scenario: Помощник работает во время обновления

- **WHEN** установщик новой версии запущен, пока помощник прежней версии загружает файлы
- **THEN** установка завершается успешно
- **AND** файлы, остававшиеся в очереди, загружаются после первой загрузки плагина новой версии

#### Scenario: Настройки после обновления

- **WHEN** плагин обновлён и проект DAW открыт заново
- **THEN** подключённое облако и привязанная папка прежние

### Requirement: Удаление сохраняет данные пользователя

Удаление плагина MUST NOT удалять очередь загрузки, состояние и сохранённый доступ к облаку.

#### Scenario: Переустановка

- **WHEN** плагин удалён и установлен снова
- **THEN** он продолжает работать с прежним облаком без повторного входа

### Requirement: Подлинность сборки

Сборка выпуска SHALL быть подписана разработчиком, а для macOS — нотаризована, когда при сборке заданы учётные данные подписи; сборка без подписи MUST быть помечена как неподписанная в имени файла.

#### Scenario: Подписанная сборка на чужом Mac

- **WHEN** подписанный и нотаризованный установщик скачан и запущен на другом Mac
- **THEN** система открывает его без предупреждения о неизвестном разработчике

#### Scenario: Сборка без учётных данных

- **WHEN** выпуск собран без учётных данных подписи
- **THEN** сборка завершается успешно, а имя файла установщика содержит пометку о том, что он не подписан

### Requirement: Единая версия

Плагин, помощник и установщик одного выпуска SHALL иметь один и тот же номер версии.

#### Scenario: Версии совпадают

- **WHEN** установщик выпуска установлен
- **THEN** версия в имени установщика, версия плагина в DAW и версия, которую сообщает помощник, совпадают

#### Scenario: Тег не совпадает с версией в коде

- **WHEN** выпуск запущен тегом, номер в котором отличается от версии в коде
- **THEN** сборка выпуска останавливается с сообщением о расхождении

### Requirement: Выпуск проверяется установкой

Каждый собранный установщик MUST быть установлен и проверен в ходе сборки выпуска: файлы на месте, помощник запускается, удаление работает.

#### Scenario: Проверка при сборке

- **WHEN** сборка выпуска создала установщик
- **THEN** он установлен на сборочной машине, помощник из установленного плагина запущен и сообщил версию, после чего плагин удалён

#### Scenario: Неработающий установщик

- **WHEN** установленный плагин не содержит помощника или помощник не запускается
- **THEN** сборка выпуска завершается ошибкой и артефакт не публикуется

### Requirement: Черновик выпуска

Сборка по тегу SHALL прикладывать установщики к черновику выпуска, который публикует человек.

#### Scenario: Сборка по тегу

- **WHEN** в репозиторий отправлен тег выпуска
- **THEN** создан черновик выпуска с установщиками для macOS и Windows, не видимый пользователям до публикации
