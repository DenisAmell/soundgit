# audio-backup Specification

## Purpose

Автоматическое резервное копирование новых аудиофайлов (DI, стемы) из наблюдаемой папки в облачное хранилище. Описывает поведение существующего прототипа: JUCE-плагин Audio Backuper и локальный сервис `backuper-service`. Audio Backuper — отдельный мини-продукт в составе SoundGit; разбор прототипа и недостающее — в `openspec/audio-backuper.md`.

## Requirements

### Requirement: Обнаружение новых аудиофайлов

Сервис SHALL ставить в очередь загрузки каждый новый файл с аудиорасширением (`.wav`, `.aif`, `.aiff`, `.mp3`, `.flac`, `.ogg`, `.m4a`, `.aac`, `.caf`, `.bwf`, `.w64`), появившийся в наблюдаемой папке или её подпапках, после того как запись файла завершена.

#### Scenario: Записан новый дубль

- **WHEN** в наблюдаемой папке появился файл `.wav` и не изменялся 2 секунды
- **THEN** файл поставлен в очередь загрузки

#### Scenario: Файл существовал до начала наблюдения

- **WHEN** наблюдение включено для папки, в которой уже есть аудиофайлы
- **THEN** существующие файлы в очередь не ставятся

#### Scenario: Не аудиофайл

- **WHEN** в папке появился файл с другим расширением или скрытый файл
- **THEN** файл игнорируется

### Requirement: Загрузка в облако с повторами

Сервис SHALL загружать файлы из очереди в облачное хранилище по пути `<корневая папка>/<ГГГГ-ММ-ДД>/<имя файла>` и повторять неудачную загрузку до 5 раз с нарастающей паузой.

#### Scenario: Успешная загрузка

- **WHEN** файл из очереди загружен
- **THEN** счётчик загруженных файлов увеличен и файл записан как последний синхронизированный

#### Scenario: Временная ошибка сети

- **WHEN** загрузка завершилась ошибкой и число попыток меньше 5
- **THEN** файл возвращается в очередь и загрузка повторяется после паузы

#### Scenario: Попытки исчерпаны

- **WHEN** загрузка файла не удалась 5 раз
- **THEN** файл удаляется из очереди и ошибка записывается в список последних ошибок

### Requirement: Управление через локальный API

Сервис SHALL принимать команды только с локального адреса `127.0.0.1`: чтение состояния, задание папки, токена и корневой папки облака, пауза, возобновление, немедленная обработка очереди и остановка.

#### Scenario: Запрос состояния

- **WHEN** получен `GET /status`
- **THEN** ответ содержит наблюдаемую папку, число файлов в очереди, число загруженных, последний файл и последние ошибки

#### Scenario: Пауза

- **WHEN** получен `POST /pause`
- **THEN** загрузка приостанавливается, а новые файлы продолжают накапливаться в очереди до `POST /resume`

### Requirement: Сохранение настроек

Сервис SHALL сохранять настройки между запусками и восстанавливать наблюдение за сохранённой папкой при старте.

#### Scenario: Перезапуск

- **WHEN** сервис перезапущен и сохранённая папка существует
- **THEN** наблюдение за ней возобновляется без действий пользователя

### Requirement: Управление сервисом из плагина без нагрузки на звук

Плагин SHALL запускать сервис как отдельный процесс, отображать его состояние и передавать ему настройки, не выполняя обработки звука.

#### Scenario: Плагин загружен в проект

- **WHEN** DAW подготавливает плагин к воспроизведению и сервис не запущен
- **THEN** плагин запускает сервис и начинает показывать его состояние

#### Scenario: Обработка звука

- **WHEN** DAW передаёт плагину аудиоблок
- **THEN** плагин возвращает его без изменений и без какой-либо работы в аудиопотоке
